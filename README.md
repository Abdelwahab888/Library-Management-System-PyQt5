# Library Management System

A professional desktop application built with Python and PyQt5, following OOP principles and Clean Code architecture.

## Features
- **CRUD Operations:** Add, View, and Delete books.
- **Search Engine:** Real-time filtering using List Comprehension.
- **Database:** SQLite integration for reliable data storage.
- **UI:** Modern and responsive interface using PyQt5.

## Architecture
- **OOP:** Implementation of Encapsulation and Abstraction.
- **Layered Design:** Separated Data Models, Logic, and UI.

## How to Run
1. Install dependencies: `pip install PyQt5`
2. Run the application: `python app.py`
